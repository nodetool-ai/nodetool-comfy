# Generated ComfyUI Nodes

This directory contains auto-generated nodetool wrappers for ComfyUI nodes.

## Overview

The nodes in this directory are automatically generated from the ComfyUI metadata using the `scripts/generate_comfy_nodes.py` script.

**Total nodes generated: 402** (excluding deprecated nodes)

## Generation

To regenerate the nodes:

```bash
python scripts/generate_comfy_nodes.py
```

This will:
1. Read `comfy_nodes_metadata.json`
2. Generate Python classes for each ComfyUI node
3. Map ComfyUI types to Python types
4. Create process methods that call the underlying ComfyUI nodes

## Structure

Each generated node:
- Inherits from `BaseNode`
- Has Pydantic fields for all inputs
- Has an `async process()` method that:
  - Imports the ComfyUI node class
  - Creates an instance
  - Calls the node's function with the provided inputs
  - Returns the result

## Node Categories

The generated nodes cover these categories:
- **sampling**: Sampling algorithms (KSampler, etc.)
- **loaders**: Model loaders (CheckpointLoader, etc.)
- **conditioning**: Text encoding and conditioning
- **latent**: Latent image operations
- **image**: Image operations and processing
- **mask**: Mask operations
- **model_patches**: Model patching utilities
- And many more...

## Type Mapping

ComfyUI types are mapped to Python types as follows:

| ComfyUI Type | Python Type |
|-------------|-------------|
| INT         | int         |
| FLOAT       | float       |
| STRING      | str         |
| BOOLEAN     | bool        |
| MODEL       | Any         |
| CLIP        | Any         |
| VAE         | Any         |
| CONDITIONING| Any         |
| LATENT      | Any         |
| IMAGE       | Any         |
| MASK        | Any         |

Complex ComfyUI types (MODEL, CLIP, VAE, etc.) are typed as `Any` since they are opaque objects passed between nodes.

## Usage

```python
from nodetool.nodes.comfy.generated.all_nodes import KSampler, EmptyLatentImage

# Create nodes
latent_node = EmptyLatentImage(width=512, height=512, batch_size=1)
sampler_node = KSampler(
    model=model,  # From CheckpointLoader
    seed=42,
    steps=20,
    cfg=7.5,
    sampler_name="euler",
    scheduler="normal",
    positive=positive_cond,  # From CLIPTextEncode
    negative=negative_cond,  # From CLIPTextEncode
    latent_image=latent,  # From EmptyLatentImage
    denoise=1.0,
)

# Process nodes
context = ProcessingContext()
latent = await latent_node.process(context)
result = await sampler_node.process(context)
```

## Validation

To validate the generated nodes:


This checks:
- Python syntax is valid
- All expected nodes are present
- All nodes have process methods
- Required imports are present
